## 2、个性化安装

根据不同.NET版本安装 ，3选1只需要安装一个dll即可（用到什么功能缺什么dll会提示你安装）

### 2.1 .Net Core 3.1 和 .NET 5-8

通用版：SqlSugarCore 带常用数据库用驱动, 不常用的缺了会提示安装

纯净版：SqlSugarCoreNoDrive 无驱动版本，用了缺什么在安装 会有错误提示你安装哪个

说明：纯净版和通用版代码是同一套没有区别，唯一区就是NUGET是否打包常用驱动的区别

选择你用的.NET版本只需要安装一个

AOT纯净版：SqlSugarCoreNoDrive.Aot 只支持 mysql sqlite sqlserver pgsql

AOT教程 [https://www.donet5.com/Home/Doc?typeId=2574](<2574.md>)

### 2.2 .Net Framework

纯净版: SqlSugar 用了缺什么在安装 会有错误提示你安装哪个

签名版: SqlSugar.StrongName 用于需要签名的项目

5.0.3.3-max 最低要求 .Net Framework 4.6

5.0.0.2-5.0.3.2 最低要求 .Net Framework 4.5

4.0-4.9.11 最低要求 .Net Framework 4.0+

### 2.3 特殊版本

.net core 2.0安装：SqlSugarCore_NetCore2 ， 选择你用的.NET版本只需要安装一个

## 4、第三方：脚手架安装

脚手架是由第三方提供的封装好的一些完整项目模版，可以快速开发

需要环境 VS2022 .NET6

| 模版名称 | 关键词 | 模板描述 |
| --- | --- | --- |
| Furion.SqlSugar.Template.Mvc | fsmvc | Mvc |
| Furion.SqlSugar.Template.Api | fsapi | WebApi |
| Furion.SqlSugar.Template.App | fsapp | Mvc/WebApi |
| Furion.SqlSugar.Template.Razor | fsrazor | RazorPages |
| Furion.SqlSugar.Template.RazorWithWebApi | fsrazorapi | RazorPages/WebApi |
| Furion.SqlSugar.Template.Blazor | fsblazor | Blazor |
| Furion.SqlSugar.Template.BlazorWithWebApi | fsblazorapi | Blazor/WebApi |

通过命令安装

```csharp
dotnet new --install Furion.SqlSugar.Template.Mvc::3.8.7
//最新版本可以通过Nuget搜索去看版本号
```

创建项目

选择相应的模版，就可以创建项目了

![image.png](<assets/4a8b5a29fc4e564ebea66006.png>)

运行项目：

配置appsettings.json文件下的连接字符串就能运行
