# MySqlConnector

## .Net Core用法

高版本 直接 DbType=DbType.MySql就行了

## .Net Framework

默认mysql.data

我们换成 DbType=DbType.MySqlConnector

并且NUGET安装下面3个DLL ( .net core自带就是mysqlconnector)

![image.png](<assets/0530dcc97820dd6c30ff3af6.png>)

注意: 如果找不到DLL

```csharp
InstanceFactory.CustomAssemblies = new System.Reflection.Assembly[] {
 typeofSqlSugar.MySqlConnector.MySqlProvider).Assembly };//扔在程序启动时
```
