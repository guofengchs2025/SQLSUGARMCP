需要升级到：5.1.4.111-preview06 及以上

已经有大量用户成功完成了项目，sqlsugar针对Vastbase 做了多处理，并且和Vastbase 处于合作关系 。有BUG可以及时找到官方

## 连接字符串

用法和PGSQL一样 ，唯一区别 在连接字符串 后面加上No Reset On Close=true

```csharp
PORT=5432;DATABASE=SqlSugar4xTest;HOST=localhost;PASSWORD=haosql;USER ID=postgres;No Reset On Close=true

//架构（schema）
字符串加上 searchpath=架构
```

## SqlSugar ORM用法

Nuget安装：SqlSugarCore 版本要求：5.1.4.111-preview06 及以上

```csharp
var db=new SqlSugarClient(new ConnectionConfig()
            {
                DbType = SqlSugar.DbType.Vastbase  
                ConnectionString = Config.ConnectionString,
                IsAutoCloseConnection = true, 
                MoreSettings=new ConnMoreSettings() {
                        DisableNarvchar=true //有些版本需要禁用Nvarchar
                 },
            });
```

## Vastbase 操作数据库

### Vastbase 查询

```csharp
db.Queryable<Student>().ToList()//查询所有
db.Queryable<Student>().Where(it=>it.Id==1).ToList()//根据条件查询
//分页  int pageIndex = 1; // pageindex是从1开始的不是从零开始的
int pageSize = 20;
int totalCount=0;
//单表分页
var page = db.Queryable<Student>().ToPageList(pageIndex, pageSize, ref totalCount);
```

### Vastbase 插入

```csharp
//返回插入行数
db.Insertable(insertObj).ExecuteCommand(); //都是参数化实现
```

## 表禁用转小写

不是纯小写表那么需要禁用自动转小写

```csharp
var db= new SqlSugarClient(new ConnectionConfig(){
           DbType = SqlSugar.DbType.Vastbase  ,
           ConnectionString = Config.ConnectionString,
           IsAutoCloseConnection = true,
           MoreSettings= new ConnMoreSettings()
           {
             PgSqlIsAutoToLower = false,//增删查改支持驼峰表
             PgSqlIsAutoToLowerCodeFirst = false, // 建表建驼峰表。5.1.3.30 
           }})
//注意 是false不要看错了
```
